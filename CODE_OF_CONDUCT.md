# Code of Conduct

flotilla follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone who takes part in the project, in issues, pull requests, discussions or anywhere else the project is represented, is expected to follow it.

In short: be respectful and patient, assume good intent, welcome newcomers, and keep criticism about the work, not the person. Harassment, personal attacks and discriminatory language are not accepted.

## Reporting

If you see or experience behaviour that breaks this code, report it to the maintainer, [raven-clown](https://github.com/raven-clown), using the contact on their GitHub profile, or use GitHub's "Report content" option on the comment or issue. Reports are kept confidential.

The maintainer may edit or remove comments, close or lock threads, and block people from the project for behaviour that breaks this code, following the enforcement guidelines of the Contributor Covenant.
